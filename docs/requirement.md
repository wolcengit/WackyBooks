# 概述

> 本文记录项目早期需求和页面草图。当前功能、支持格式及运行方式以 [README](../README.md) 为准。

- 系统为PDF,EPUB,TXT,图片阅读工具
- 系统设计见后面界面设计
- 系统使用Go+Vue3

# 按钮Search
查找针对所有书籍

```text
--------------------------------------------------------------
[Return]    ___________________[Search]           Admin[V]
--------------------------------------------------------------
<以书籍图片方式显示>

--------------------------------------------------------------
```

# 点击书籍图片

```text
--------------------------------------------------------------
[Return] [Download]   <book name>
--------------------------------------------------------------

<book read area>

--------------------------------------------------------------
```
